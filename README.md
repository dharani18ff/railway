# E-Commerce Website

A simple e-commerce website built with HTML, CSS, and JavaScript.

## Features

- Product listings with images
- Responsive design
- Add to cart functionality (alert notification)

## How to Run

Open `index.html` in your web browser.

## Adding Images

To add your own product images, place them in an `images/` folder and update the `src` attributes in `index.html`.

For example:

```html
<img src="images/product1.jpg" alt="Product 1">
```

The current setup uses placeholder images from https://via.placeholder.com/.
